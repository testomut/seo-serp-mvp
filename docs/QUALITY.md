# Проверка качества разметки

**Выборка:** 20 случайных URL из 118 во вкладке Sites (`random.Random(20261031).sample`, список отсортирован по URL),
проверены вручную по текущим страницам 31.10.2026. Проблемные примеры заранее не подбирались.

**Точность в процентах не заявляется:** 4 страницы из 20 недоступны напрямую (геоблок, ошибка сертификата),
страницы меняются, а HTML на момент разметки не сохранялся.

## Что нашла проверка

| Поле | Итог |
|---|---|
| Relevant / Type | В основном верно: 14 обзорников = yes, 3 сайта операторов = no. 2 `unknown` - сайты не открылись (реальные обзорники). Спорный случай - блог оператора (Rocketplay): по условию задачи no |
| Brands | Главная проблема - **полнота**: терялись бренды-логотипы (только в `alt` картинок) и хвосты длинных списков (лимит 12 тыс. символов). Плюс лишние сущности: бесплатная игра Cosmo Spins, Polymarket, Replay Poker |
| Contact | Где найден, обычно ведёт на сайт владельца, но иногда слабый: страница вакансий, email автора |

## Что исправлено (разметка v2)

- Текст картинок (`alt`) передаётся в LLM как `[image: Lucky Tiger]`; лимит текста поднят до 30 тыс. символов.
- Промпт: пройти все рейтинги и карточки; не считать брендами игры, социальные казино, бесплатный покер, рынки прогнозов.
- Контакты сортируются: реклама/партнёрство → общий Contact; вакансии отбрасываются.
- Страница «not available in your country» с кодом 200 считается неоткрывшейся, а не сайтом без брендов.
- Версия разметки в `config.LABEL_VERSION`: ответы старой версии перепроверяются при следующем прогоне.
