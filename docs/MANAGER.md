# Инструкция для менеджера

Программа каждое утро ищет в Google (Канада, телефон) фразы из списка и проверяет найденные сайты:
подходит ли сайт для размещения наших брендов, какие казино на нём уже есть и как связаться с владельцем.

Всё, что нужно, - **одна Google-таблица**. Ничего устанавливать не надо.

## Где смотреть результаты

Откройте таблицу (ссылка приходит в Telegram после каждого прогона). Первая вкладка **Help** коротко описывает все вкладки и колонки.

**Вкладка Sites** - все найденные сайты, подходящие сверху.

| Колонка | Что значит |
|---|---|
| URL, Domain | Адрес страницы и сайта |
| Relevant | `yes` - подходит для размещения, `no` - нет, `unknown` - сайт не открылся |
| Type | `review` - обзор/рейтинг, `casino` - сайт самого казино, `wiki`, `news`, `forum`, `other` |
| Brands | Какие казино упомянуты на странице |
| Contact | Email или страница «Contact» для связи |
| Reason | Короткое объяснение, почему так решено |
| Checked by | Кто решал: `gemini` (ИИ) или `rules` (простые правила, менее точно) |
| Best position | Лучшее место сайта в Google среди наших фраз |
| Keywords | По каким фразам сайт найден |

**Вкладка Positions** - история: на каком месте был сайт по каждой фразе в каждый день.
Пусто в колонке даты - в тот день сайта в топ-10 не было.

## Как добавить или убрать фразу

Вкладка **Keywords**:
- **добавить** - новая строка: фраза в колонке `keyword`, `yes` в колонке `active`;
- **выключить** - поменять `yes` на `no`. История по фразе сохранится.

Изменения подхватятся на следующем прогоне.

## Как запустить вручную

Обычно не нужно: прогон идёт сам каждое утро. Если нужно срочно:
- в Telegram-боте отправить `/run`, через 5-15 минут придёт сводка;
- или на странице проекта в GitHub: вкладка **Actions** → **daily** → **Run workflow**.

## Как поменять время ежедневного запуска

Время задано в файле `.github/workflows/daily.yml`, в строке:

```yaml
- cron: "0 7 * * *"   # every day at 07:00 UTC
```

1. На странице проекта в GitHub откройте `.github/workflows/daily.yml` и нажмите карандаш («Edit»).
2. Поменяйте второе число - это час по **UTC** (0-23). Первое число - минуты.
3. Нажмите «Commit changes».

Время указывается по UTC, а не по местному времени:

| Хотите запуск в | Зимой (ноябрь-март) | Летом (март-ноябрь) |
|---|---|---|
| 9:00 Торонто | `"0 14 * * *"` | `"0 13 * * *"` |
| 9:00 Париж / Варшава | `"0 8 * * *"` | `"0 7 * * *"` |
| 9:00 Киев | `"0 7 * * *"` | `"0 6 * * *"` |

GitHub может начать запуск с опозданием, иногда на несколько часов (бесплатный тариф, очередь), это нормально. Если результаты нужны
срочно, используйте `/run` в боте или кнопку «Run workflow».

## Команды бота

| Команда | Что делает |
|---|---|
| `/run` | Запустить прогон сейчас |
| `/status` | Дата последнего прогона и итоги |
| `/new` | Подходящие сайты, лучшие позиции сверху |
| `/keywords` | Какие фразы отслеживаются |
| `/add online casino alberta` | Добавить фразу |
| `/remove interac casino` | Выключить фразу |

Если бот ответил не сразу - он «спал», первый ответ занимает до минуты.
