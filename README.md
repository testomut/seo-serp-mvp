# SEO SERP MVP

[![tests](https://github.com/testomut/seo-serp-mvp/actions/workflows/tests.yml/badge.svg)](https://github.com/testomut/seo-serp-mvp/actions/workflows/tests.yml)
[![daily](https://github.com/testomut/seo-serp-mvp/actions/workflows/daily.yml/badge.svg)](https://github.com/testomut/seo-serp-mvp/actions/workflows/daily.yml)

Каждый день собирает топ-10 Google.ca (mobile) по списку ключей, сохраняет позиции с историей и с помощью LLM
размечает каждый новый URL: подходит ли сайт для размещения, какие казино-бренды упомянуты, контакт для связи.

**Результат прогона:** [`results.xlsx`](results.xlsx) (вкладки Sites и Positions) и Google Sheet (ссылка в письме).
Инструкция для менеджера: [docs/MANAGER.md](docs/MANAGER.md). Подключение Sheets, GitHub и бота: [docs/SETUP.md](docs/SETUP.md).

## Запуск

```bash
python -m venv .venv && .venv\Scripts\activate      # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                                  # ключи вписать по желанию
python main.py                                        # результат: results.xlsx
python -m pytest                                      # тесты
```

**Работает без единого ключа:** без `SEARCHAPI_KEY` (или `SERPAPI_KEY`) берётся демо-выдача, без `GEMINI_API_KEY` сайты размечаются
правилами. Каждый ключ включает свою часть, колонка «Checked by» показывает, чем размечен сайт.

## Как устроено

`main.py` → `serp_mvp/pipeline.py`, дальше по шагам: `serp.py` (выдача) → `storage.py` (позиции) →
`fetch.py` (страница, email, ссылка Contact) → `classify.py` (Gemini, при ошибке `rules.py`) →
`storage.py` / `sheets.py` (выгрузка) → `notify.py` (Telegram/Slack). `bot.py` - пульт в Telegram.

- **Без дублей:** позиции хранятся по ключу (дата, фраза, позиция); повторный прогон в тот же день заменяет данные
  дня, новый день добавляет историю. URL размечается один раз (повторно, только если раньше его размечали правила).
- **Ошибки:** ретраи с паузой для поиска, страниц и LLM; упавшая фраза не останавливает прогон и повторится завтра;
  при сбое LLM срабатывают правила. Контакт LLM выбирает только из найденных на странице, не выдумывает.
- **Бренды без дублей:** LLM пишет один бренд по-разному («TonyBet», «Tonybet Casino»). Перед выгрузкой
  варианты склеиваются в одно имя (из `data/brands.txt` или самое частое): 829 названий → 452 бренда.
- **Ежедневно:** GitHub Actions (`.github/workflows/daily.yml`) в 07:00 UTC, база коммитится обратно в репозиторий.

## Безопасность ключей

Ключи никогда не попадают в код: локально они в `.env` (в `.gitignore`), для ежедневного запуска в
GitHub Secrets (зашифрованы, в логах скрыты как `***`), для бота в переменных окружения Render.
Карта нигде не привязана, поэтому утечка ключа в худшем случае исчерпает бесплатный лимит. Токен GitHub
для бота ограничен одним репозиторием и правом запуска Actions.

## Инструменты и почему

| Задача | Выбор | Почему |
|---|---|---|
| Выдача | SearchApi.io (или SerpApi) | Мобильная выдача и гео Канада, бесплатный тариф; свой парсинг Google упирается в капчу. Два сервиса с одинаковым API - запасной вариант на случай блокировки |
| LLM | Gemini Flash | Бесплатный тариф, JSON-ответ; для классификации страниц точности хватает |
| Хранение | SQLite + Google Sheets | SQLite - надёжная основа без сервера, Sheets - удобный вид для менеджера |
| Расписание | GitHub Actions | Бесплатно, без сервера, кнопка ручного запуска |
| Бот | Telegram на Render (free) | Бот не хранит данных: `/run` запускает Actions, остальное читает Sheet |

## Стоимость прогона

**$0** на бесплатных тарифах (10 поисков SearchApi, Gemini free tier). На платных: первый прогон (~100 URL)
примерно $0.15 за выдачу + $0.10-0.20 за LLM; следующие дни дешевле, размечаются только новые URL.

## Что сознательно не сделал

- Проход партнёрских редиректов (на какой бренд ведёт ссылка).
- Анализ не только первой страницы сайта: контакт часто лежит на /contact, мы сохраняем ссылку на неё.
- Сайты под Cloudflare и с JS-рендерингом не открываются через `requests`; такие помечаются `unknown`.
- Claude/OpenAI/Ollama как альтернативы Gemini (добавляются одной функцией в `classify.py`).
- Команды бота в Slack (в Slack только уведомления). На бесплатном Render бот просыпается 30-60 секунд.
